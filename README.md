# Apache Hive: развёртывание и загрузка данных

Hive 4.0.0-alpha-2 развёртывается через Docker Compose: HiveServer2 для нескольких
клиентов, отдельный metastore и PostgreSQL. Сервисы соединяются по именам внутри
Docker-сети, IP-адреса в настройках не нужны.

## Запуск

Нужны Linux x86_64, Bash и Docker с Compose v2.20+.
Первый запуск скачивает образы из интернета. Если Docker требует `sudo`,
добавьте его перед командами `bash` и `docker`.

```bash
git clone https://github.com/MkSerdyuk/HSE-Data-Platforms-3.git
cd HSE-Data-Platforms-3
bash start.sh
```

Скрипт развёртывает стенд, загружает данные и проверяет их двумя клиентами
одновременно. При успехе выводится:
`complete`.

## Загрузка и проверка

В `data/` лежат два CSV с учебными продажами за `2026-10-01` и `2026-10-02`.
Каждая строка содержит поля: `sale_id`, `product`, `amount`.
`load.sh` создаёт таблицу `lab.sales` и загружает каждый файл в отдельную партицию
по `sale_date`. Получается 6 строк, по 3 на дату. Повторная загрузка заменяет
данные без дубликатов:

```bash
bash load.sh
bash check.sh
```

`check.sh` двумя клиентами проверяет число строк, уникальность номеров продаж
и суммы по датам: `600.00` за `2026-10-01`, `1500.00` за `2026-10-02`.

Для ручного подключения выполните в одном или нескольких терминалах:

```bash
docker compose exec hiveserver2 beeline -u jdbc:hive2://hiveserver2:10000/default -n hive
```

## Остановка

```bash
docker compose down
```
